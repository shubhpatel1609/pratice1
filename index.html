README.md

Shubh Patel is a hands-on cloud and DevOps practitioner, currently building infrastructure skills through real labs instead of just slides — provisioning EC2 fleets, wiring up load balancers, and chasing down the occasional 503 until it's actually fixed.

Recent work spans RHEL 9 administration, containerized deployments with Docker, and end-to-end CI/CD pipelines that build, push, and ship code to live servers without a human clicking "deploy" by hand.

Also builds full stack web applications, using Docker for containerization, GitHub for version control and collaboration, and VS Code as the daily driver for writing, debugging, and shipping code.

Comfortable being the person who reads the error log line by line — because that's usually where the fix is hiding.
